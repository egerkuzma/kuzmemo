# Kuzmemo

**[English version → README.md](README.md)**

Говорите со своим календарём. Kuzmemo — приложение в строке меню macOS: нажмите клавишу и скажите, что нужно, — *«напомни послезавтра отправить отчёт»*, *«завтра в 11 созвон с командой»*, *«что у меня на сегодня?»* — и запись появится в собственном календаре, а на вопрос вам ответят голосом.

Распознавание речи работает на вашем Mac. Смысл фразы понимает Claude через консольную утилиту `claude`, которой вы уже пользуетесь по подписке Claude; приложение доверяет только строгому проверенному JSON и само считает все даты.

Интерфейс и голосовые ответы двуязычные: **английский и русский**. Изначально приложение проектировалось под распознавание русской речи.

## Возможности

- **Одна клавиша.** **Fn**: короткое нажатие включает запись без рук (она остановится, когда вы замолчите), удержание — запись, пока клавиша нажата. **⌃⌥M** работает без дополнительных разрешений. **Esc** отменяет запись.
- **Понимает обычные фразы.** Напоминания, события, задачи и заметки; «завтра», «в следующий понедельник», «через два часа», «по будням в 18:00», «двадцать пятого числа». На неоднозначные фразы («в следующую пятницу») приложение не гадает, а коротко спрашивает голосом и показывает кнопки; ответить можно голосом, нажатием на вариант или текстом.
- **Отвечает на вопросы вслух.** «Что на сегодня?», «что у меня завтра», «что просрочено», «найди всё про бюджет». Простые вопросы обрабатываются локально примерно за полсекунды.
- **Собственный календарь** (SQLite, ничего никуда не синхронизируется): сетка месяца, список дня, «Входящие» для записей без даты и для фраз, которые пока не удалось обработать, повторяющиеся записи, полнотекстовый поиск с учётом словоформ, редактор с живым описанием правила повтора.
- **Ничего не теряется.** Запись сохраняется до распознавания, текст — до отправки; если `claude` недоступен, фраза ждёт во «Входящих» и обрабатывается позже. Любое изменение, сделанное голосом, можно отменить (плашка, меню, журнал отмены переживает перезапуск).
- **Уведомления под вашим контролем.** Системные уведомления с вашими сроками (например, за 10 и 5 минут до встречи и в её начале), несколько напоминаний в день для дел без времени, свои звуки или системные, кнопки «Отложить», тихие часы.
- **Голоса.** Системный голос или необязательный нейросетевой голос [Silero](https://github.com/snakers4/silero-models) (русский), который работает локально в небольшом Python-помощнике.
- **Глоссарий.** Научите приложение именам и терминам: как их слышит распознавание, как они пишутся и как их должен произносить голос. Сначала он пуст; слова хранятся в вашей базе, их можно экспортировать и импортировать в JSON.
- **Приватность.** Звук не покидает Mac и удаляется после расшифровки. В Claude уходят только распознанный текст, слова из глоссария и заголовки нескольких ближайших записей календаря.

## Требования

- macOS 26 или новее; рекомендуется Apple silicon (распознавание использует Neural Engine).
- Xcode 26 или новее (Swift 6.2+) для сборки.
- Установленный и авторизованный [Claude Code](https://claude.com/claude-code) (`claude auth login`). Kuzmemo вызывает `claude -p`, то есть использует вашу подписку Claude; режима с API-ключом нет.
- Около 2 ГБ диска под модель распознавания (и ещё около 800 МБ под необязательный нейросетевой голос).

## Сборка и запуск

```bash
git clone <этот репозиторий> && cd kuzmemo

# 1. Сертификат для подписи кода, один раз. macOS привязывает разрешения на микрофон и «Мониторинг ввода» к подписи
#    приложения; при подписи «ad hoc» они сбрасывались бы после каждой пересборки. Связка ключей > Ассистент сертификации >
#    Создать сертификат (Тип: самоподписанный корневой, Тип сертификата: подпись кода). Затем укажите его скрипту:
export KUZMEMO_SIGN_IDENTITY="<имя сертификата или SHA-1>"   # либо запишите в файл signing/identity (он в .gitignore)

# 2. Сборка, подпись, установка в ~/Applications и запуск
scripts/run_app.sh --prod
```

При первом запуске разрешите **Микрофон**, **Мониторинг ввода** (нужен для клавиши Fn; сочетание ⌃⌥M работает и без него) и **Уведомления**. В **Настройки → Распознавание** скачайте модель. Если Fn открывает выбор эмодзи или диктовку, поставьте в *Системные настройки → Клавиатура → «Нажатие клавиши 🌐»* значение **Ничего не делать**.

Необязательный нейросетевой голос: `scripts/install_silero.sh` (нужен Python 3.10+; скрипт создаёт своё окружение и скачивает модель в `~/Library/Application Support/Kuzmemo/silero`), затем выберите его в *Настройки → Озвучка*.

`scripts/run_app.sh` без `--prod` собирает *автоматическую сборку* для сквозных скриптов (см. ниже).

## Как пользоваться

| Скажите | Что произойдёт |
|---|---|
| «Напомни послезавтра позвонить в банк» | Напоминание на весь день, о нём скажут в выбранные вами часы |
| «Завтра в одиннадцать созвон с командой» | Событие на 11:00, с ранним предупреждением, если оно включено |
| «Каждый понедельник в десять планёрка» | Повторяющееся событие |
| «Что у меня на сегодня?» | Ответ вслух из вашего календаря, без сети |
| «Перенеси встречу с Анной на четверг» | Нужная запись изменится (с возможностью отмены) |
| «В следующую пятницу созвон в три» | «Какую пятницу?» с двумя кнопками; ответьте голосом или нажмите |

Всплывающее окно в строке меню показывает сегодняшний день, последний результат с кнопками **Отменить / Изменить** и текстовое поле, которое проходит тот же путь, что и речь. **⌘,** открывает настройки; окно **Календарь** — полный вид месяца.

## Как это устроено

```
клавиша → микрофон → Whisper на устройстве (WhisperKit) → текст
        → локальный быстрый путь для простых вопросов, либо `claude -p` (без инструментов, строгая JSON-схема)
        → проверка (разрешённые действия, даты считает приложение, правила уточнений)
        → SQLite + журнал отмены → плашка / HUD / голосовой ответ / уведомления
```

Три цели SwiftPM: `KuzmemoCore` (логика и хранилище без интерфейса, полностью покрыты тестами), `KuzmemoSTT` (WhisperKit), `Kuzmemo` (приложение). Замысел, контракт с моделью, модель данных и риски описаны в [docs/PLAN.md](docs/PLAN.md); рабочие заметки для участников — в [docs/HANDOFF.md](docs/HANDOFF.md).

## Тесты

```bash
swift test                                   # модульные тесты; «золотой набор» воспроизводит записанные ответы модели без сети
KUZMEMO_LIVE_CLAUDE=1 swift test --filter liveAgainstClaude   # золотой набор против настоящего `claude -p`
```

Сборка для разработки открывает управляющий сокет, поэтому скрипты могут управлять настоящим приложением без человека: `scripts/e2e/voice.py`, `calendar.py`, `settings.py`, `notifications.py`, `silero.py` (сначала запустите `scripts/run_app.sh`; голосовые заготовки создаёт `scripts/fixtures/make_synth.sh`). Эта сборка беззвучна, не реагирует на клавиатуру и не открывает микрофон. То, что может проверить только человек (настоящий микрофон, Bluetooth, баннеры уведомлений, запуск при входе), перечислено в `docs/HANDOFF.md`.

## Данные и приватность

Всё хранится в `~/Library/Application Support/Kuzmemo` (база, модели). Звук — временный файл, он удаляется, как только сохранён текст. Текст фразы, глоссарий и заголовки ближайших записей уходят в Anthropic через Claude Code; больше ничего. Расшифровки и тексты календаря считаются недоверенным вводом для модели (без инструментов, строгая схема, разрешённые действия, мягкое удаление с отменой).
